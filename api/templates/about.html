☀️ Solar Energy Predictor

A full-stack machine learning application for predicting solar energy output based on weather parameters.

🎯 Project Overview

This project implements multiple machine learning algorithms to predict short-term solar energy output based on 12 weather parameters. It features a Flask REST API and an interactive web interface for real-time predictions.

Based on the CS229 final project — "What weather features are the most influential for solar energy prediction at University of Illinois?"

🧠 Machine Learning Models

  • Gradient Boosting — Ensemble model with 35 trees, tree complexity 15
  • Random Forest — 100 decision trees with max depth 15
  • LSTM Neural Network — 2-layer LSTM with 24-hour sequence input

📊 Feature Importance

Based on our analysis, the most influential weather parameters for solar prediction are:

  • Temperature (28%)
  • Cloud Coverage (25%)
  • Humidity (18%)
  • Dew Point (12%)
  • Wind Speed (7%)
  • Visibility, Pressure, Altimeter (10% combined)
